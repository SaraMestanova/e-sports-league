# 🏆 E-Sports League

### A Modern & Responsive E-Sports Community Website

E-Sports League is a responsive frontend website designed for a competitive gaming community. It features a bold gaming-inspired interface, vibrant neon visuals, and structured sections that bring players, teams, and fans together.

Built with **HTML5 and CSS3**, the project focuses on clean page structure, responsive layouts, and visual consistency.

## ✨ Features

- 🎮 **Gaming-Inspired Design** — Dark theme with colorful neon accents.
- 🏆 **Hero Section** — Eye-catching championship trophy and welcome message.
- 📱 **Responsive Layout** — Designed to adapt to desktop, tablet, and mobile screens.
- 🧭 **Navigation** — Simple navigation between website sections.
- 🎯 **Mission & Objectives** — Information about the gaming community.
- 🤝 **Official Partners** — Dedicated section highlighting partners.
- 📅 **Upcoming Matches** — Organized schedule of gaming competitions.
- 🔗 **Footer** — Additional information and useful links.

## 🛠️ Technologies Used

- **HTML5** — Semantic structure and page content.
- **CSS3** — Styling, Flexbox, layouts, and responsive design.
- **Visual Studio Code** — Development environment.
- **Git & GitHub** — Version control and source code hosting.

## 📸 Preview

The website includes a gaming-inspired homepage with a colorful championship trophy, information sections, partner logos, and upcoming match listings.

## 🚀 Getting Started

1. Clone the repository:

   `git clone https://github.com/SaraMestanova/e-sports-league.git`

2. Open the project folder.
3. Open `index.html` in your browser.

No additional installations or dependencies are required.
